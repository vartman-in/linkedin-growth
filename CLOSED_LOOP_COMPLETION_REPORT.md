```typescript
const DEFAULT_CONFIG: LearningConfig = {
  minObservationsForPattern: 3,
  minObservationsForWeakSignal: 2,

  patternExpiryDays: 30,
  confidenceThreshold: 0.6
};
```

**Enforcement Points:**
- `detectTopicPreferences()` - Checks `total >= minObservationsForPattern`
- `detectFormatPreferences()` - Checks `data.count >= minObservationsForPattern`
- `detectPerformancePatterns()` - Checks `performanceData.length < minObservationsForPattern`
- `detectEngagementPatterns()` - Checks `weeks.length < 3`

**Status Classification:**
- 1-2 observations → INSUFFICIENT_DATA (rejected)
- 3-4 observations → EARLY_SIGNAL (accepted with lower confidence)
- 5-9 observations → EMERGING_PATTERN (accepted)
- 10+ observations → ESTABLISHED_PATTERN (accepted with high confidence)

### Phase 8 - Connect Learning to Opportunity Scoring
**Status: IMPLEMENTED**

**File Modified:** `server/services/intelligence/content-opportunity.service.ts`

**Changes:**
1. Added `closedLoopRepo` to constructor
2. Added `learningAdjustment` field to `OpportunityScore` interface
3. Added `calculateLearningAdjustment()` method
4. Integrated learning adjustment into scoring calculation

**Scoring Formula:**
```
BASE_SCORE (10 dimensions)
+ LEARNING_ADJUSTMENT (±10 points max)
= OVERALL_SCORE
```

**Learning Adjustment Logic:**
- Queries active learning patterns for workspace
- Finds topic preference patterns matching current topic
- Calculates adjustment based on historical acceptance rate
- Bounded to ±10 points to prevent extreme swings
- Returns INSUFFICIENT_DATA if no patterns exist

**Example Output:**
```json
{
  "overallScore": 78.5,

    "reason": "12 historical opportunities on this topic with 75% acceptance rate",
    "supportingObservations": 12,
    "confidence": "STRONG_PATTERN"
  },
  "breakdown": { ... }
}
```

**Transparency:**
- Every adjustment includes reason
- Supporting observation count shown
- Confidence level indicated (INSUFFICIENT_DATA, EARLY_SIGNAL, EMERGING_PATTERN, STRONG_PATTERN)
- No hidden calculations

## 8. Scoring

**Location:** `server/services/intelligence/content-opportunity.service.ts:scoreOpportunity()`

**Formula:**
```
BASE_SCORE = Σ(dimension_score × weight) for 10 dimensions

LEARNING_ADJUSTMENT = calculateLearningAdjustment(workspaceId, topic)
  - Query active learning patterns
  - Find topic preference pattern
  - Calculate: (acceptance_rate - 0.5) × 20
  - Bound to ±10 points
  - Return with reason and confidence

OVERALL_SCORE = BASE_SCORE + LEARNING_ADJUSTMENT
```

**Learning Adjustment Integration:**
- ✅ Queries `learning_patterns` table
- ✅ Filters by workspace_id
- ✅ Finds topic_preference patterns
- ✅ Matches pattern_data.topic to current topic
- ✅ Calculates adjustment from acceptance_rate
- ✅ Bounds adjustment to ±10 points
- ✅ Returns INSUFFICIENT_DATA if no patterns
- ✅ Includes reason, observation count, confidence level

**Transparency:**
- ✅ Every score includes breakdown
- ✅ Learning adjustment includes reason
- ✅ Supporting observations counted
- ✅ Confidence level indicated
- ✅ No hidden calculations
