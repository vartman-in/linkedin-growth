   - Time range tracking

4. **learning_insights** - Human-readable insights
   - Insight types: recommendation, observation, warning, opportunity

   - Actionable suggestions
   - Confidence and observation counts
   - Expiration dates

   - Job types: source_refresh, trend_recalc, opportunity_recalc, learning_recalc, analytics_aggregate
   - Status tracking: PENDING, RUNNING, COMPLETED, FAILED
   - Error handling and result storage
   - Provider-agnostic (works with cron, BullMQ, cloud schedulers)

   - user_id, entity_type, entity_id, provenance
   - Enhanced indexing for pattern detection

## Key Features

### 🔄 Closed-Loop Learning Flow

```
User Interacts with Intelligence
    ↓
Feedback Recorded (accepted/dismissed/edited/converted/published/rejected)
    ↓
Pattern Detection Analyzes Feedback
    ↓
Patterns Created (topic preferences, format preferences, performance patterns, engagement patterns)
    ↓
Insights Generated (recommendations, observations, warnings, opportunities)
    ↓
Opportunity Scoring Incorporates Learned Signals
    ↓
Future Recommendations Adjusted
    ↓
User Interacts Again
    ↓
(Cycle Continues)
```

### 📊 Pattern Detection

**Topic Preferences**
- Analyzes accepted vs dismissed opportunities by topic
- Calculates acceptance rate
- Creates patterns for topics with sufficient observations (≥3)
- Confidence based on observation count and acceptance rate

**Format Preferences**
- Analyzes converted opportunities by format
- Identifies frequently used formats
- Creates patterns for formats with sufficient usage (≥3)

**Content Performance**
- Analyzes performance metrics by platform
- Calculates average engagement
- Creates patterns for high-performing platforms (avg engagement >10)

**Engagement Patterns**
- Analyzes feedback over time
- Detects increasing/decreasing trends
- Creates patterns for significant trends (change ≥2)

### 💡 Insight Generation

**Recommendations**
- Actionable suggestions based on patterns
- Example: "Create more content about AI agents" (if topic preference detected)
- Includes evidence summary and confidence

**Observations**
- Factual statements about detected patterns
- Example: "High performance on LinkedIn platform"
- Includes observation count and time range

**Warnings**
- Alerts about negative patterns
- Example: "Declining engagement trend detected"
- Includes action suggestion

**Opportunities**
- Positive patterns to leverage
- Example: "Growing engagement trend - continue current strategy"
- Includes evidence and confidence

### 🎯 Adaptive Opportunity Scoring

Enhanced from 10 to 12 scoring dimensions:

1. Topic relevance (15%)
2. Audience relevance (15%)
3. Timeliness (15%)
4. Evidence strength (15%)
5. User expertise relevance (10%)
6. Novelty (10%)
7. Source diversity (5%)
8. Conversation potential (5%)
9. Content saturation (5%)
10. Confidence (5%)
11. **Historical user preference (NEW)** - Based on learned topic/format preferences
12. **Historical performance (NEW)** - Based on learned performance patterns

Each dimension includes:
- Score (0-100)
- Reason (human-readable explanation)
- Evidence (data supporting the score)

### 📈 Performance Tracking

**Platform-Neutral Metrics**
- impressions, views, likes, comments, shares, saves, clicks, follows, profile visits, leads, conversions

**Provenance Tracking**
- VERIFIED_PLATFORM - From official platform APIs
- USER_ENTERED - Manually entered by user
- IMPORTED - Imported from external source
- SYSTEM_CALCULATED - Calculated from other metrics

**No Fake Data**
- Only stores real metrics
- If data doesn't exist, nothing is stored
- Clear provenance for all metrics

### 🎓 Explainability

Every AI-generated object includes:
- **Why it was generated** - Pattern or signal that triggered it
- **What evidence supports it** - Observation count, evidence IDs
- **What sources were used** - Feedback records, performance data
- **What assumptions were made** - Confidence thresholds, time ranges
- **How confident is the system** - Confidence score (0.0-1.0)
- **What data is missing** - Insufficient data indicators

Example insight:
```json
{
  "title": "Strong preference for AI agents content",
  "description": "Your workspace shows 85% acceptance rate for AI agents topics",
  "evidence_summary": "Based on 12 observations with 85% acceptance rate",
  "confidence": 0.85,
  "observation_count": 12,
  "generated_by": "DETERMINISTIC",
  "is_actionable": true,
  "action_suggestion": "Consider creating more content about AI agents"
}
```

### ⚙️ Configurable Thresholds

The learning system uses configurable thresholds to prevent false patterns:

```typescript
{
  minObservationsForPattern: 3,      // Minimum to detect a pattern
  minObservationsForWeakSignal: 2,   // Minimum for weak signal
  minObservationsForStrongPattern: 5, // Minimum for strong pattern
  patternExpiryDays: 30,              // Pattern expiration
  confidenceThreshold: 0.6            // Minimum confidence for insight
}
```

These can be customized per workspace or globally.
